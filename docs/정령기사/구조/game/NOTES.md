- 2026-10-13: 사용자 요청으로 `Source/정령기사`에 문어 게임과 독립된 Unity 프로젝트 「잿빛 서약」 생성. 기존 프로젝트 파일 변경 없음.
- 1인 액션 생존 구조: 시작 화면 → 룬 획득 → 네 정령 동행/자동 공격 → 잔재 획득·축복 → 45초 간격 세 파동 → 망각의 왕 → 승리/패배·재시작.
- 이동 5.9, 검격 간격 0.43초/기본 피해 27, 회피 쿨타임 1.6초/무적 0.3초. 기본 체력 100. 이동속도 투자는 없음.
- 정령 공격은 적이 사거리 12 안에 있으면 각자 기본 3초마다 발동. 잿불은 고정 화염 문양, 서리는 감속 파편 3개, 가시는 다중 속박, 뇌광은 연쇄 번개. 같은 룬은 계약 단계 최대 3 및 체력 12 회복.
- 새 게임의 최고 기록·음향 설정은 별도 PlayerPrefs 키를 사용한다. 일반 Windows 빌드에서 검증 코드는 제외된다.
