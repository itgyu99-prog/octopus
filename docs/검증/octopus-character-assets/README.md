# 회색 문어 캐릭터 에셋

사용자 그림의 회색 몸체·둥근 머리·짧은 네 촉수·3자 입을 기준으로 만든 픽셀 에셋이다. 현재 게임 캐릭터에는 미적용 상태다.

사용자가 선택한 에셋은 [final 폴더](final/README.md)에 따로 모은다. 대기와 승리를 보관했으며, 이후 완성하는 동작도 같은 폴더를 갱신한다. 실제 게임 반영은 사용자가 일괄 적용을 요청할 때 진행한다.

## 투명 PNG

| 동작 | 스프라이트 시트 | 프레임 수 | 권장 시간 |
|---|---|---:|---|
| 대기 | [idle-64.png](idle-64.png) | 12 | 각 250 ms, 호흡 3초 |
| 이동 | [walk-64.png](walk-64.png) | 4 | 각 130 ms |
| 멈춤 | [stop-64.png](stop-64.png) | 4 | 100 / 90 / 120 / 650 ms |
| 피격 | [hit-64.png](hit-64.png) | 4 | 100 / 90 / 140 / 750 ms |
| 승리 | [victory-64.png](victory-64.png) | 16 | 각 200 ms, 왕복 3.2초 |

각 시트는 64×64 셀을 가로로 붙인 RGBA PNG다. 정규화된 발 기준 pivot=(0.5, 0.125). 원본 생성 시트는 source/에 보존했다. 셀 분리·공통 크기 조정은 원본을 다시 그리지 않고 nearest-neighbor로 수행했다. 동작별 원본 비례를 유지하고 프레임 간 발 기준을 맞췄다.

Unity 가져오기 권장: Sprite (2D and UI), Multiple, Grid by Cell Size 64×64, Filter Mode Point, Compression None, Generate Mip Maps 끔. Pixels Per Unit 48을 시작점으로 삼고 게임의 기존 캐릭터 월드 크기에 맞춘다. 피격·멈춤은 앞 3프레임을 한 번 재생한 뒤 마지막 프레임에서 대기로 전환한다. 피격·멈춤 GIF의 마지막 긴 대기 시간은 미리보기의 반복 간격이다. 승리는 16프레임을 각 200ms로 반복한다.

## 미리보기

- [전체 동작 GIF](all-states-preview.gif)
- [승리 춤 GIF](victory-preview.gif)
- [대기](idle-preview.gif), [이동](walk-preview.gif), [멈춤](stop-preview.gif), [피격](hit-preview.gif)

대기는 사용자가 선택한 첫 번째 12프레임 시안을 그대로 GIF와 가로 아틀라스로 조립했다. 후속 사선 자세·입 방향 수정은 사용자가 취소해 반영하지 않았다. 점눈과 작은 입을 유지하며 위쪽 몸체가 천천히 오르내리는 3초 호흡이다. 원본 4열×3행의 투명 간격으로 셀을 분리하고, 높이 중앙값44픽셀 공통 배율과 발 하단y56을 적용했다. 최종 프레임 높이는43~46픽셀이다. 프레임마다 따로 크기를 맞추거나 입을 다시 그리지 않았다.

승리는 기존 생성 시트를 참고하지 않고 사용자 원본 그림의 왼쪽 아래 승리 포즈에서 새로 제작했다. 반쯤 감긴 눈·비뚤어진 미소·둥근 몸·네 짧은 촉수를 살렸다. 화면 왼쪽 바깥 촉수 하나가 가슴 앞에 가로로 놓인 채 천천히 허리 쪽으로 내려갔다 돌아온다. 반대편 촉수와 두 안쪽 발은 쉬는 자세를 유지한다. 양팔 교대·빠른 펀치·가슴 팝 대신 한쪽 팔의 느린 흔들림이 중심이다.

첨부 `녹화_2026_10_16_15_19_03_217.mp4`를 imageio-ffmpeg 0.6.0/FFmpeg 7.1로 실제 디코딩했다(5.53초, 488×852, 30fps). 0.2초 간격의 28개 프레임에서 한쪽 가로 팔이 가슴에서 허리 쪽으로 천천히 낮아지는 흐름을 확인하고 생성 도구의 동작 참고로 사용했다. 음성 트랙의 16kHz 모노 표본 88,422개가 모두 0인 무음이므로 음악 BPM이나 정확한 음악 동기화는 확인할 수 없다. 현재 3.2초 왕복은 보이는 팔의 속도를 참고한 해석이며, 실제 BPM을 측정한 결과가 아니다. 녹화 영상 프레임과 음원은 배포 에셋에 포함하지 않았다.

승리 원본은 4열×4행이며, 알파 분포의 빈 간격으로 셀을 분리했다. 알파 128 초과 영역의 경계를 잘라 전체 높이 중앙값이 44픽셀이 되는 공통 배율을 적용했다. 위쪽 45% 머리 외곽 중심을 x=32, 하단 발 기준을 y=56으로 정렬했다. 최종 16프레임 높이는 모두 44픽셀이다. 투명 가로 아틀라스는 1024×64다. GIF는 256×256 nearest-neighbor 확대, 배경 RGB(222,216,199), 무한 반복이다. 전체 미리보기는 새 승리 한 번 분량인 3.2초이며 각 동작의 실제 프레임 전환 시점을 사용한다.

제작: imagegen 내장 도구. 정확한 생성 프롬프트와 참고 자료는 [prompts.json](prompts.json), 셀 크기·피벗·프레임별 시간과 타이밍 한계는 [manifest.json](manifest.json)에 기록했다. PNG 알파와 셀 크기, 모든 GIF 프레임의 디코딩 및 승리 16프레임의 외형·촉수 연결을 확인했다. 이동·멈춤·피격·승리 개별 에셋은 이번 대기 작업에서 유지했다.
