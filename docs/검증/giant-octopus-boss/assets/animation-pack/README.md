# 문어 보스 애니메이션 에셋

움짤 및 제공된 포즈 시트에서 동작별 에셋을 모았습니다. 원본 시트는 보존했습니다.

1. `01_문어_본체.png` — 문어 본체
2. `02_다리_좌우_내리치기_시트.png` — 좌우 타격 포즈 시트. 반대 방향은 좌우 반전해 사용합니다.
3. `03_다리_상하_내리치기_시트.png` — 상하 내리치기 시트
4. `04_땅굴_들어가기_시트.png` — 땅굴 진입 4프레임
5. `05_땅굴_나오기_시트.png` — 땅굴 등장 4프레임
6. `06_다리_대기_시트.png` — 고정 뿌리 시트 첫 행의 대기 4프레임

좌우 내리치기의 재생 순서는 원본 4열×5행, 20포즈를 기준으로 정리했습니다. 대기/준비 → 내리치기 → 바닥 접촉 → 긴 접촉 포즈 → 회복 → 대기 흐름이며, 긴 접촉 프레임을 12번 뒤에 넣었습니다. 긴 접촉 포즈 원본은 `02a_다리_좌우_긴접촉포즈.png`입니다.

`07_좌우내리치기_재생시트.png`는 600×500px 셀, 5열×5행(마지막 4칸 투명)이며 뿌리 피벗은 셀 중심 `(300, 460)`입니다. 왼쪽 방향은 셀을 좌우 반전해도 뿌리 위치가 유지됩니다. `08_좌우내리치기_순서미리보기.gif`는 같은 흐름을 오른쪽과 왼쪽에 차례로 보여주며, `09_좌우내리치기_재생정보.json`에 프레임 순서와 시간을 기록했습니다. 흙/구덩이는 다리 프레임 안에 포함되어 있고 별도 에셋으로 분리하지 않았습니다.
