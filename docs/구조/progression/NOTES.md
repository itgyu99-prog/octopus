# 최근 변경

- 2026-10-13: 클리어 능력 선택은 새 선택지 3개 중 1개를 고르는 절차를 2회 진행한다. 첫 보상은 즉시 반영하고 두 번째 선택 완료까지 대기한다. `ChoiceRevision`으로 이전 선택창의 중복 RPC를 거부하며 짧은 입력 중복 방지도 적용한다.
- 상한에 도달한 강화는 후보에서 제외한다. 유효 종류가 3개 미만일 때는 남은 유효 항목을 반복 표시해 3개 카드를 유지한다.
- 선택/3초 카운트다운 중 이동과 E 획득을 허용한다. 공격과 적 피해는 멈춘다. 다음 스테이지 시작 시 모든 기존 필드 액터를 정리하고 중앙 오브젝트·새 보스 등을 다시 만든다. 획득한 속성·요소·특수요소·강화는 유지한다.
- 특수요소를 포함한 미획득 보상은 전환 시 정리하므로, 5보스 보상은 두 번째 선택 완료 전에 획득한다.
- 속성 드랍률 5%→2%. 두 플레이어 모두 이미 가진 속성은 후보에서 제외한다. 확률은 `GameplayRules.json`에서 변경한다.
