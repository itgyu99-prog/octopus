# 최근 변경

- 2026-10-13: 기본 속성은 4칸이며 중복 획득으로 성장하지 않는다. 획득 순서대로 공용 공격 주기(기본 3초)에 하나씩 발동한다. 합성 후 재료와 공격 순서를 유지하고 일반 요소 3칸을 처음부터 사용할 수 있다.
- 물은 기본 8방향 전방위 발사, 전기는 확산 전류. 스테이지 ‘속성 공격 강화’로 반복 횟수가 1→2→3회로 늘며 간격은 0.22초다. 불은 내부 전체 지속 피해와 범위 증가를 적용한다. 물 발사 수·반복 간격은 `GameplayRules.json`에 있다.
- 기본 피해 계수와 투사체 속도·크기·수명은 기존 값을 사용한다. 합성 6종 효과는 유지한다. 사용되지 않던 `AbilityRunner`의 옛 기본 속성/고리 공격 코드를 정리했다.
- 특수요소는 실제 5스테이지 보스 처치 뒤에만 해금·2개 드랍한다. 10·15 보스에서는 드랍하지 않는다.
