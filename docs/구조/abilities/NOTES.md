# 최근 변경

- 2026-10-13: 기본 속성 4칸은 각자 기본 3초 쿨타임으로 발동한다. 동시에 준비된 속성은 같은 틱에 모두 발동하며 기존 쿨타임 감소 강화는 각 타이머에 적용한다. 중복 획득 성장 없음, 합성 재료 보존, 요소 3칸은 유지한다.
- 불은 발동 위치에 설치되어 2.5초 동안 유지되는 화염 지대다. 물은 8방향 발사를 유지하면서 반복 발사 및 다음 발동마다 12도씩 방향을 변경한다. 반복 간격 0.22초 및 강화에 따른 반복 횟수는 유지한다.
- 풀은 0.16초 간격 4회 공격, 회당 기본 3개 대상(이전 1개), 속성 단계마다 대상 +1개다. 사거리 9와 대상당 기본 피해 19는 유지한다.
- 탄산수는 발동마다 PET병 형상의 액터 5개를 맵의 무작위 유효 위치에 생성한다. 각 병은 속도 6으로 이동하며 0.8초마다 방향을 무작위 변경하고 경계/바위에서 반사한다. 지속 4초, 반경 1.2, 0.25초마다 기본 피해 25 및 기존 요소 쿨타임은 유지한다. 위치·수명·피해·무작위 이동은 서버가 결정하고 기존 액터 스냅샷으로 복제한다.
- 특수요소는 실제 5스테이지 보스 처치 뒤에만 해금·2개 드랍한다. 10·15 보스에서는 드랍하지 않는다.
