## 2026-10-14 밸런스 검증 및 A~D 승인안 (구현 전 기록)

- DLL 분석문과 다운로드 HTML v2를 현재 소스·GameplayRules.json·UpgradeTuning.asset과 대조했다. 이 기록 시점에는 게임 코드와 HTML 원본을 수정하거나 Unity를 실행하지 않았다.
- Elapsed는 서버 Time.deltaTime이며 보스 생존·선택·카운트다운·게임오버에서 정지한다. 일반 적 HP는 생성 시 고정, 속도는 현재 Elapsed를 사용한다. 보스 HP는 (2600+6t)*0.7*(stage/5), 웨이브는 인원 보정 없이 최대 일반 적 72마리다.
- 거대는 개별 asset 기준 HP 8~15배, 피해 1.8~2.5배, 속도 0.5~0.8배, 크기 3~3.5배다. 등장 확률/상한은 3~4:2%/1, 5~7:4%/2, 8~10:6%/3, 11+:8%/3이며 해금·화면 밖 조건이 추가된다.
