# 불 속성·우주·음양오행 수정 (2026-10-27)

적용 프로젝트: 바탕화면 `octopusBW/Source/문어_유한맵`, 브랜치 `octopus-black/white`.

## 적용 내용

1. 불 속성 직접 피해 24 → 31.2 DPS, 화상 피해 4 → 5.2 DPS. 두 수치 모두 30% 상향했으며 실제 Resources 설정과 코드 기본값을 함께 변경했습니다.
2. 우주 별의 생성 좌표에서 카메라·시전자 위치 의존성을 제거했습니다. 일반 맵과 보스 맵 각각의 해변 좌표를 기준으로 필드 전체의 모래 위에 분포합니다. 별 수는 레벨 1에서 180개, 레벨 6에서 240개입니다. 별당 피해를 나눠 기존 총 피해량은 유지합니다.
3. 맵이 어두워지면서 은은한 흰색·청색·은색 별과 가는 별빛 연결이 서서히 나타납니다. 별은 서로 다른 방향·속도로 출발하고 부드럽게 방향을 바꾸며 적을 추적합니다. 실제 이동 경로를 기록해 곡선 빛줄기와 열 단계의 잔상을 표시합니다.
4. 전용 투명 폭발 에셋을 추가했습니다. 몬스터 크기에 따라 0.7~2.1 월드 단위로 조절하고 0.46초 동안 퍼짐·사라짐·작은 빛 조각을 조합했습니다. 생성 프롬프트와 원본 위치는 `Art/Celestial/V2/README.md`에 있습니다.
5. 음양오행의 작은 곡옥을 시전자 주변 16개에서 필드 전체 144개 지점으로 옮겼습니다. 모든 곡옥을 동시에 표시하지 않고 시차를 두고 작게 올라온 후 터집니다. 시전자가 움직여도 발생 지점은 월드 좌표에 고정됩니다. 큰 곡옥의 기존 궤도·전투 피해는 유지합니다.

## 검증

Unity 6000.5.7f1에서 컴파일하고 실제 로컬 호스트를 시작해 서버 스킬·렌더링을 실행했습니다. `문어/우주 전필드 개선 검증 및 화면 저장` 메뉴에서 재실행할 수 있습니다.

- 일반 맵과 보스 맵의 별·작은 곡옥이 모래 위에서 필드 전체에 분포.
- 카메라의 위치와 줌, 시전자 위치를 바꿔도 별 생성 위치가 동일.
- 서버 화염 발사체의 피해 31.2 및 화상 설정 5.2 확인.
- 전필드의 모든 우주 별이 타격하고 레벨 1 총 피해량 3510 유지.
- 여러 방향으로 출발, 실제 경로 잔상 렌더링, 몬스터 크기 제한 확인.
- 마지막 별과 폭발 종료 후 어둠 해제 및 이펙트 종료.
- 작은 곡옥의 상승·폭발 전환 및 시전자 이동 시 위치 고정.
- 실행 화면을 캡처해 별빛·어둠 강도와 폭발 크기를 검토하고 수정.

최종 결과와 실행 이미지는 `Logs/CelestialField/`에 저장됩니다. 실제 2대의 네트워크 플레이와 저사양 PC 성능 측정은 수행하지 않았습니다.
