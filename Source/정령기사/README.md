# 잿빛 서약 · ASHEN OATH

사용자 요청으로 기존 문어 게임과 분리해 만든 새로운 1인용 정령기사 액션 생존 게임이다.

## 바로 플레이

이 폴더의 `플레이.cmd`를 더블클릭하거나 `Build/Windows/AshenOath.exe`를 실행한다. 실행 파일 옆의 `AshenOath_Data`, DLL 및 `MonoBleedingEdge` 폴더를 함께 유지한다.

Unity 편집은 **Unity 6000.5.7f1**에서 이 폴더를 프로젝트로 열고 `Assets/Scenes/Sanctum.unity`를 실행한다. 빈 씬에서 런타임 초기화가 성소·캐릭터·UI를 생성한다.

## 조작

| 입력 | 행동 |
|---|---|
| WASD / 방향키 | 이동 |
| 마우스 | 검격 방향 |
| 좌클릭 유지 / J | 검격 |
| Space / 우클릭 | 그림자 걸음: 짧은 무적 회피, 1.6초 쿨타임 |
| E | 처치로 충전한 서약 해방 |
| 1 / 2 / 3 | 축복 선택 |
| Esc | 일시정지 / 재개 |
| M | 음향 켜기 / 끄기 |

## 여정

- 시작 지점 오른쪽의 주황 룬에 다가가 첫 정령과 계약한다. 다음 미계약 룬의 방향과 거리는 오른쪽 위 HUD가 안내한다.
- 잿불은 2.5초 동안 남는 화염 문양, 서리는 감속 파편 3개, 가시는 여러 적 속박, 뇌광은 연쇄 번개를 사용한다.
- 계약한 정령은 기사 옆을 따라다니며 사거리 안의 적을 자동 공격한다. 정령마다 기본 3초의 독립 쿨타임을 갖는다.
- 같은 룬을 다시 얻으면 정령 계약이 최대 3단계까지 성장하고 생명력 12를 회복한다.
- 적을 쓰러뜨리면 서약 잔재가 떨어진다. 잔재를 모아 공격력, 생명력, 정령 계약 중 하나의 축복을 고른다.
- 각 파동은 45초다. 세 파동 뒤 **2분 15초**에 나타나는 망각의 왕을 쓰러뜨리면 승리한다. 생명력이 0이면 패배하며 바로 다시 시작할 수 있다.
- 최고 처치 기록과 음향 설정은 로컬에 저장한다. 진행 중인 판은 저장하지 않는다.

## 파일 구조

- `Assets/Scripts/OathGame.cs`: 이동·검격·정령·전투·획득·성장·상태 전환·합성 음향
- `Assets/Scripts/OathArt.cs`: 원본 절차적 기사·정령·적·룬·석조 성소 아트
- `Assets/Scripts/OathHud.cs`: 한국어 시작·안내·HUD·강화·일시정지·결과 화면
- `Assets/Editor/OathBuild.cs`: Windows 일반/검증 빌드
- `Assets/Scripts/OathChecks.cs`: 개발 빌드의 명시적 자동 검증. 일반 빌드에서 제외

`python tools/project_index.py --project ashen-oath --category game`으로 작업 폴더 루트에서 관련 코드를 조회한다. 기존 문어 게임의 색인은 기본 명령을 그대로 사용한다.

## 빌드와 검증

Unity 메뉴 `잿빛 서약 / Windows 빌드`는 `Build/Windows`를 갱신한다. 배치 실행 메서드는 `AshenOath.Editor.OathBuild.Windows`다. `-oath-validation`을 추가하면 `Build/Validation` 개발 빌드가 생성된다.

검증 빌드를 `-oath-selftest` 인자로 실행하면 실제 렌더링과 게임 흐름을 확인하고 종료 코드를 반환한다. 검증 로그는 `Logs`, 확인 이미지는 `Build/Validation/Screenshots`를 재사용한다. 검증에서 최고 기록은 저장하지 않는다.

이번 버전은 한 성소·네 정령·세 파동·한 보스로 구성된 1인 플레이 첫 버전이다. 온라인 협동, 중간 저장, 여러 맵은 구현하지 않았다. 이전 문어 게임의 Unity 프로젝트·아트·네트워크 코드에는 의존하지 않는다.
